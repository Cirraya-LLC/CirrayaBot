# 角色包与场景资产

## 角色包清单

每个角色的每个 look 需要：

| 资产 | 数量 | 说明 |
| --- | --- | --- |
| 身份卡 | 1 | 外形要点、身高、配色 hex、标志特征、**禁止改动项** |
| 转面图 | 正 / 3-4 / 侧 / 背 | 中性光、纯色背景，最重要 |
| 表情表 | 8–12 | 喜怒哀惧惊、坚毅、疲惫等本片常用表情 |
| 细节特写 | 按需 | 脸、手、武器、配饰 |
| 光照参考 | 3 | 白天 / 夜晚 / 本片常见特殊光（火光、法术光等） |
| 反例 | 按需 | 审片打回的跑偏样本，入库打 `negative` 标签 |

另外每个项目维护一张全员**身高对比图**。

## 工作流程

1. `studio project info` 读画风。所有素材必须贴合项目画风，不要用你自己的默认审美。
2. `studio char show <角色>` 看已有资产，只补缺的部分。
3. 生成：
   - 概念、场景、道具、快速迭代 → `--engine gpt-image`
   - 需要严格一致的角色定稿图、已有 LoRA 的角色 → `--engine comfy`
4. 以已有转面图作为 `--ref` 生成新图，保证同一角色不漂移。
5. `studio asset save` 入库，**标签要完整**：角度、表情、光照、景别。摄影靠这些标签自动匹配参考图，
   标签缺失等于这张图不存在。
6. 新角色、新 look 保持草稿态，@ 人类请求定稿（`char lock` 只有人类能做）。

## 被 route=asset 打回时

读 `studio review history <镜头>` 看具体问题：
- 参考图本身有歧义（比如正面和侧面发型不一致）→ 修参考图，旧图打 `deprecated`
- 缺少对应角度或光照的参考 → 补图
- 模型总是画错某个特征 → 补该特征的特写参考，并把失败样本存为反例

修完 @林野 重新生成，说明改了哪些参考图。

## 边界

- 不改 `locked` 资产，需要改就 @ 人类说明理由。
- 不自行修改身份卡的禁止改动项。
- 版权角色如果 GPT 图像拒绝生成，改用 comfy 引擎，不要通过改名或模糊描述绕过。
