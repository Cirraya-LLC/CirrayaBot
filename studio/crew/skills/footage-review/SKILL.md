# 审片

## 流程（每个镜头）

1. `studio shot show <镜头>` 读镜头定义、衔接关系、studio 初筛分数。
2. `studio char show` 读相关角色的身份卡和禁止改动项。
3. `studio shot sheet <镜头>` 获取候选对比图，同时对照定稿转面图。
4. 逐个候选按下表打分，选最高分且无一票否决项的候选。
5. 通过 → `shot approve`；全部不合格 → `shot reject`，写明理由和打回方向。

## 评分标准（每项 1–5 分）

| 项目 | 看什么 |
| --- | --- |
| 角色一致性 | 脸、发型、服装、配色是否和定稿参考一致 |
| 动作完成度 | 是否完成镜头定义的动作，起止状态对不对 |
| 镜头语言 | 景别、角度、运镜是否符合定义 |
| 画面质量 | 形变、闪烁、多余肢体、画面崩坏 |
| 画风统一 | 是否符合项目画风 |
| 衔接 | 和上下镜的位置、朝向、道具、光线是否连得上 |

**一票否决**：违反身份卡的禁止改动项；明显肢体崩坏（多手指、融化、穿模）；角色认不出是谁。

通过线：无一票否决，且平均分 ≥ 3.5（项目可在 `project info` 里调整）。

## 打回要求

`--reason` 必须具体到能直接改：
- ✗ "角色不像"
- ✓ "候选 1–4 蛮吉的发色都偏棕，身份卡要求黑色；候选 3 最接近，但右手出现第六根手指"

`--route` 选择：
- `prompt`：生成方案的问题 → 自动流转给林野
- `asset`：参考图有歧义或缺失 → 流转给苏棠
- `plan`：镜头设计本身不可行 → 流转给顾衡

**同一镜头第 3 次打回，不再自动流转，直接 @ 人类**，附三次的打回理由摘要。

## 审片态度

- 你的标准不随进度压力降低。宁可打回，不放烂片进剪辑。
- 但也别因为吹毛求疵拖死流程：不影响观感的小瑕疵写进 note，照样通过。
- 看不清、拿不准的地方如实说"对比图分辨率不足以判断"，不要猜。
- 通过的候选里如果有可以借鉴的写法，写进 note，方便林野积累。

整批审完，给顾衡发一条汇总：通过几镜、打回几镜、主要问题类型。
