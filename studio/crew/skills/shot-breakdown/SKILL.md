# 镜头拆解

## 流程

1. `studio project info` 读画风和基调；`studio scene show <场次>` 读剧本段落。
2. 列出本场需要的角色、造型、场景，逐个 `studio char show` / `studio loc show` 确认资产存在且足够。
   缺了就先 @苏棠 补，写清楚缺什么（哪个角色、哪个造型、需要哪些角度或表情），等补齐再继续。
3. 拆镜头，写 shots.json，`studio shot plan` 入库。
4. @林野 交接，标出重点和难点镜头。

## 镜头 JSON

```json
{
  "id": "S03-SH004",
  "duration_s": 5,
  "shot_size": "中景",
  "angle": "低角度 3/4",
  "camera_move": "缓推",
  "characters": [{"name": "蛮吉", "look": "战斗装", "expr": "咬牙", "action": "拔刀起身"}],
  "location": "断崖",
  "light": "黄昏逆光",
  "story_beat": "被逼到绝境后第一次反击",
  "continuity": {"in_from": "S03-SH003 结尾蛮吉跪地", "out_to": "S03-SH005 刀光特写"},
  "priority": "hero"
}
```

`priority` 取值：`hero`（关键镜头，值得多抽卡、用更强模型）/ `normal` / `filler`（过场）。

## 拆镜头原则

- **一镜一件事。** 一个镜头只承载一个动作或一个情绪转折。视频模型对复合动作命中率很低，
  "拔刀、转身、跳起" 要拆成三镜。
- **时长保守。** 默认 3–5 秒，超过模型稳定时长的动作拆开，用剪辑衔接。
- **避开模型弱项。** 多人肢体接触、手部精细操作、画面内文字，能用景别或剪辑回避就回避，
  比如用反应镜头代替直接展示接触瞬间。
- **写清衔接。** 每镜的 `continuity` 必须写上下镜关系，审片靠它查穿帮。
- **景别有节奏。** 连续三镜同景别要有理由。

## 被 route=plan 打回时

说明问题出在镜头设计本身（动作太复杂、时长不合理、衔接冲突）。改镜头定义而不是改 prompt，
必要时拆成多个镜头，改完 @林野。
