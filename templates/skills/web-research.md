# Researching on the web

1. Restate the question in one line, and what a good answer has to contain (a number, a date, a yes/no, a list).
2. Search: open `https://html.duckduckgo.com/html/?q=<words>` in the browser and `read` the results. Try two or
   three phrasings; one query is rarely enough.
3. Open the most promising primary sources first: the official site, the documentation, the original announcement,
   the dataset. Press and forums are leads, not proof.
4. Check every fact that matters in a second, independent source. If two sources disagree, say so and say which you
   trust more and why.
5. Note the date of each source. Something true last year may not be true now.

Deliver:
- The answer first, in one or two sentences.
- Then the supporting points, each with its source URL.
- Then what you could not confirm, plainly marked as such.

Don't present a guess as a finding. "I couldn't find this" is a valid answer.
