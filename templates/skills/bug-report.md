# Reporting a bug

Before writing anything, reproduce it. A bug you saw once and can't reproduce is reported as such.

Then write:
- **Title** — what is wrong, in one line ("Saving a draft with an emoji in the title fails").
- **Steps** — numbered, from a clean start, the fewest that still show it.
- **Expected** — what should happen.
- **Actual** — what happens instead, with the exact error text.
- **Where** — URL or command, browser or system, version if you can find it.
- **Evidence** — a screenshot or the relevant lines of output.
- **Notes** — anything that makes it go away or worse, and how often it happens.

Keep each report to one problem. If you found three, write three.
